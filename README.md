# sparse_data_computer_vision
A computer vision pipeline using PyTorch and EfficientNet-B3. implemented transfer learning and progressive unfreezing to optimize image classification accuracy for complex visual datasets.

No need to run this file! It took about 1 hour for me to train this model, so feel free to take a look at the accuracy findings at the bottom of the imageClassifier file: 70.09%! 

For context, the challenge was using computer vision to classify images, but limiting the data the model could train on. In fact, there are 100 classes of images of all kinds, with each class only having 10 images to learn from.
